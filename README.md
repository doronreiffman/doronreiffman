AI and backend engineer in Jerusalem. I build AI tools and the data systems under them, mostly in Python and TypeScript on AWS.

### Projects

- **[Flight board archive](https://github.com/doronreiffman/flights-archive)**: keeps every 15-minute version of Ben Gurion airport's public flight board and turns the archive into a history page for each flight. Python, AWS Lambda, S3, DuckDB. [Live site](https://dt4564wsgvijr.cloudfront.net)
- **[Israeli grocery price tracker](https://github.com/doronreiffman/il-grocery-prices)**: collects, every morning, the price files Israeli supermarket chains must publish by law, and prices one basket of 32 products across five chains. Python, AWS Lambda, S3, DuckDB. [Live site](https://d153udx05irk2f.cloudfront.net)
- **[Job Scout](https://github.com/doronreiffman/job-scout)**: a daily AI job-search assistant. It reads company careers feeds, LinkedIn alert emails and WhatsApp job groups, screens out what can't fit, scores the rest against your resume with Claude, and emails one digest. Python, Claude API, SQLite.
